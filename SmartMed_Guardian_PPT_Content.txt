# DEEP TECHNICAL EXPLANATION (For Viva Prep)

### 1. Project Architecture (MVVM)
The project follows Clean Architecture principles using MVVM (Model-View-ViewModel).
- View: Built with Jetpack Compose. It is reactive; it simply displays the state provided by the ViewModel.
- ViewModel: Acts as a bridge. It uses viewModelScope to run ML inference in a background thread so the UI doesn't freeze (ANR).
- Repository: This is the Single Source of Truth. Even if we change our ML model or add a Database (Room), the ViewModel doesn't need to change.

### 2. CameraX Pipeline
We use PreviewView to show the camera feed. When the user clicks "Capture," we use ImageCapture.takePicture. The resulting ImageProxy is converted to a Bitmap. Crucially, we handle Rotation. Cameras on mobile devices often capture in landscape; we rotate the bitmap based on the device's sensor orientation so the AI "sees" the pill upright.

### 3. ML Inference (TensorFlow Lite)
- Loading: The .tflite model is a flatbuffer file loaded from the assets folder into memory as a ByteBuffer.
- Preprocessing: The model expects a specific input (e.g., 224x224 pixels, RGB). We use ImageProcessor to Resize the captured photo and Normalize it (dividing by 255 to get values between 0 and 1).
- Inference: The interpreter.run() method executes the neural network.
- Post-processing: The output is an array of probabilities. We use ArgMax (finding the index with the highest value) to determine the medicine name and return a Confidence Score.

### 4. Neumorphic UI Implementation
Standard Compose buttons are "flat." To get the Neumorphic look, we draw two shadows behind a surface: a Light Shadow (top-left) and a Dark Shadow (bottom-right). This creates the illusion that the button is pushed out of the background.

# VIVA QUESTIONS AND ANSWERS (30 Questions)

1. Q: What is SmartMed Guardian?
    * A: It is an Android application that uses AI to identify medicines and help users manage their medication safely.
2. Q: Why use Kotlin instead of Java?
    * A: Kotlin is more concise, null-safe, and is the recommended language by Google for modern Android development.
3. Q: What is Jetpack Compose?
    * A: It is Android’s modern toolkit for building native UI using a declarative approach, replacing traditional XML layouts.
4. Q: Explain MVVM architecture.
    * A: It stands for Model-View-ViewModel. It separates the UI logic (View) from the business logic (ViewModel) and data (Model) to make code modular and testable.
5. Q: Why is CameraX better than Camera2?
    * A: CameraX is a higher-level API that handles device compatibility and lifecycle management automatically, making it much more stable.
6. Q: What is TensorFlow Lite?
    * A: It is a lightweight version of TensorFlow designed specifically for mobile and embedded devices to run ML models locally.
7. Q: Why do you resize the image to 224x224?
    * A: Because the pre-trained neural network (like MobileNet) was designed with an input layer of that specific size.
8. Q: What is "Inference" in ML?
    * A: Inference is the process of using a trained model to make predictions on new, unseen data (like a new photo of a pill).
9. Q: What is a "Confidence Score"?
    * A: It is a percentage indicating how sure the AI is about its prediction. A 0.95 score means 95% confidence.
10. Q: How do you handle camera permissions?
    * A: We use the Accompanist Permissions library to request the CAMERA permission at runtime and show a rationale if it's denied.
11. Q: What is the role of the FakeMedicineClassifier?
    * A: It acts as a fallback/mock for testing navigation and UI flows when the real TFLite model isn't being used or is unavailable.
12. Q: Why use a Repository pattern?
    * A: To decouple the data sources (ML, Database, API) from the ViewModel, following the "Separation of Concerns" principle.
13. Q: What is "Neumorphism"?
    * A: A design style using soft shadows to mimic physical, tactile objects, making the UI more intuitive for elderly users.
14. Q: How does the app work offline?
    * A: Since the TFLite model is bundled inside the app (on the "Edge"), it doesn't need an internet connection for identification.
15. Q: What was the Gradle conflict you mentioned?
    * A: A conflict between TFLite support libraries and metadata versions was resolved by excluding redundant dependencies in build.gradle.
16. Q: What is a "Coroutine" in Kotlin?
    * A: A design pattern for asynchronous programming that allows us to run long tasks (like ML inference) without blocking the main UI thread.
17. Q: What is StateFlow?
    * A: A state-holder observable flow that emits updates to the UI whenever the application state changes.
18. Q: How do you handle different screen sizes?
    * A: By using Compose's flexible layout system (Columns, Rows, Boxes) and DP units to ensure the UI scales correctly.
19. Q: What happens if the AI identifies the wrong medicine?
    * A: The app shows the confidence score. If it's low, it advises the user to retake the photo or check manually. (Safety First).
20. Q: Why is "Edge AI" important in healthcare?
    * A: It ensures data privacy (no medical images uploaded to the cloud) and works instantly in areas with poor connectivity.
21. Q: What is "Normalization" in image processing?
    * A: Converting pixel values from 0-255 to 0.0-1.0 so the mathematical operations in the neural network are more stable.
22. Q: What are "Hilt" and "Dependency Injection"?
    * A: Hilt is a library that provides objects (like the Repository) to classes that need them, making the app modular and easier to test.
23. Q: What is a "Splash Screen"?
    * A: The initial screen shown while the app initializes resources (like the TFLite model) in the background.
24. Q: How do you capture an image in CameraX?
    * A: Using the takePicture method of the ImageCapture use case, which returns an ImageProxy.
25. Q: What is "ArgMax"?
    * A: A mathematical function used to find the index of the highest probability in the output array of the ML model.
26. Q: What is "Phase 2" of your project?
    * A: The implementation of the Medicine Recognition System, including CameraX and TFLite integration.
27. Q: Can the app identify multiple pills at once?
    * A: Currently, it is optimized for single-pill identification to maintain high accuracy and simplicity.
28. Q: What is the benefit of "Soft UI" for visually impaired users?
    * A: The high-contrast shadows and large "3D" buttons are easier to distinguish than flat, thin icons.
29. Q: How would you add a new medicine to the system?
    * A: By retraining the TFLite model with new images and updating the label mapping in the code.
30. Q: What is your future plan for this project?
    * A: Adding Phase 3 (Prescription Management) and Phase 4 (Caregiver Escalation) to make it a complete adherence ecosystem.
